# Налив нефти из ж/д цистерн в танкер (CODESYS, Structured Text)

Учебный проект: PLC-логика налива **80 т** нефти из двух вагонов-цистерн в танкер.
Среда: **CODESYS V3.5 SP22 Patch 4**, язык **ST**, проверка в симуляторе (CODESYS Control Win).

**Демо-симулятор (в браузере):** https://kylsh.github.io/railcar-to-tanker-loading/

> **Важно.** Проект учебный и не является системой безопасности. Реальные эстакады налива
> требуют аппаратной ESD-цепи, независимой защиты от переполнения, взрывозащищённого
> оборудования и сертифицированных решений (ориентиры для изучения: IEC 61511, API 2350,
> API RP 2003, ATEX).

## Что делает программа

- Автомат состояний налива: проверка условий, открытие задвижек, пуск насоса, медленный старт,
  основной налив, снижение скорости перед концом, остановка, закрытие задвижек.
- Счётчик массы: интегрирование расхода (т/ч) по времени цикла.
- Защиты: аварийная остановка, заземление, газ, утечка, переполнение танкера, сухой ход насоса,
  высокое давление, нет потока, задвижки не открылись.
- Встроенная модель процесса (`bSimMode = TRUE`): задвижки, расход и давление имитируются
  программой, оборудование не нужно.

## Схема процесса

```
 Вагон №1 --[XV-101]--+
                      +-- коллектор --[PT-101]--> P-101 (насос + ЧРП) --[PT-102]--[FT-101]--[XV-201]--> рукав --> ТАНКЕР
 Вагон №2 --[XV-102]--+     (всас)                                     (нагнетание)  (расход)                       [LSHH]
```

## Быстрый запуск

Нужно: Windows, установленный CODESYS V3.5 SP22 (или новее) и CODESYS Control Win V3 x64
(устанавливается вместе с CODESYS).

### Вариант А. Открыть готовый проект

1. Скачай репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуй архив.
2. Запусти CODESYS и выбери **Файл → Открыть проект**, укажи файл из папки `project/`.
3. Нажми **F11** (Компиляция → Собрать). Должно быть `0 ошибок`.
4. Убедись, что CODESYS Control Win запущен (значок в области уведомлений Windows, пункт Start PLC).
5. **Онлайн → Вход** (Alt+F8), согласись на загрузку, затем **F5** (старт).
   Внизу должна гореть зелёная плашка **РАБОТА**.

### Вариант Б. Собрать проект из исходников

1. **Файл → Создать проект**, шаблон **Стандартный проект**, устройство **CODESYS Control Win V3 x64**,
   язык `PLC_PRG`: **ST**.
2. Правый клик по `Application → Добавить объект → DUT`, тип **Перечисление**, имя `E_LoadState`.
   Вставь содержимое `src/E_LoadState.st` целиком (вместе с `TYPE` и `END_TYPE`).
3. Открой `PLC_PRG`. Из файла `src/PLC_PRG.st`:
   - всё до `END_VAR` включительно вставь в **верхнее** окно (объявления);
   - всё, что идёт после `END_VAR`, вставь в **нижнее** окно (код).
4. Двойной клик по `MainTask`, интервал задачи **T#100ms** (должен совпадать с `rCycleS`).
5. **F11**, затем вход (Alt+F8) и **F5**, как в варианте А.

## Как проверить в симуляторе

1. Добавь в окно Watch переменные: `eState`, `nFaultCode`, `rLoadedMass`, `rFlow`, `rPumpSpeed`,
   `rDischPress`, `bPumpRun`, `bStartCmd`.
2. Подожди 3 секунды, пока `bValvesClosedFb` станет TRUE.
3. Для быстрого теста поставь `rMaxFlow = 4000` (налив займёт около двух минут). Значение
   записывается через Prepare value и Write values (Ctrl+F7).
4. Запиши `bStartCmd = TRUE`. Старт срабатывает только при переходе FALSE → TRUE, поэтому
   перед повторным запуском верни `bStartCmd` в FALSE.
5. Следи за `eState`: `10 → 20 → 30 → 40 → 50 → 60 → 70 → 80 → 90`.

| Значение `eState` | Состояние |
|---|---|
| 0 | `ST_IDLE` ожидание |
| 10 | `ST_CHECK` проверка условий |
| 20 | `ST_OPEN_VALVES` открытие задвижек |
| 30 | `ST_PUMP_START` пуск насоса |
| 40 | `ST_LOAD_SLOW` медленный налив (первые 2 т) |
| 50 | `ST_LOAD_FULL` основной налив |
| 60 | `ST_RAMP_DOWN` снижение скорости (последние 5 т) |
| 70 | `ST_STOP_PUMP` остановка насоса |
| 80 | `ST_CLOSE_VALVES` закрытие задвижек |
| 90 | `ST_DONE` налив завершён |
| 100 | `ST_FAULT` авария |

### План тестов

| № | Действие | Ожидание |
|---|---|---|
| 1 | `bStartCmd` = TRUE | Цепочка состояний идёт до `ST_LOAD_SLOW` |
| 2 | Ждать налива | Скорость насоса 30% → 100% → 25%, `rLoadedMass` растёт до ~80 |
| 3 | Достигнута масса | `ST_STOP_PUMP` → `ST_CLOSE_VALVES` → `ST_DONE`, `bDone` = TRUE |
| 4 | `bEStopOK` = FALSE во время налива | `ST_FAULT`, код 1, насос и задвижки выключены |
| 5 | `bOverfill` = TRUE | `ST_FAULT`, код 5 |
| 6 | `rSuctionPress` = 0.1 дольше 3 с | `ST_FAULT`, код 8 |
| 7 | `bStopCmd` во время налива | Остановка насоса и закрытие задвижек, `bTargetReached` = FALSE |
| 8 | Сброс при неустранённой причине | Остаёмся в `ST_FAULT` |

Сброс аварии: устранить причину, затем импульс `bResetCmd` (TRUE, потом FALSE).

## Коды аварий (`nFaultCode`)

| Код | Причина |
|---|---|
| 1 | Аварийная остановка (ESD) |
| 2 | Нет заземления |
| 3 | Загазованность |
| 4 | Утечка |
| 5 | Переполнение танкера |
| 6 | Нет потока после пуска насоса |
| 7 | Высокое давление нагнетания |
| 8 | Низкое давление на всасе (сухой ход) |
| 9 | Задвижки не открылись вовремя |

## Основные параметры

| Параметр | Значение | Смысл |
|---|---|---|
| `rTargetMass` | 80 т | Сколько нужно налить |
| `rSlowMass` | 2 т | Медленный старт |
| `rRampMass` | 5 т | Снижение скорости в конце |
| `rStopLead` | 0.05 т | Упреждение остановки с учётом инерции потока |
| `rSlowSpeed` / `rFullSpeed` / `rFinalSpeed` | 30 / 100 / 25 % | Скорости насоса |
| `rDischMax` | 10 бар | Максимум давления нагнетания |
| `rSuctionMin` | 0.3 бар | Минимум давления на всасе |
| `rMaxFlow` | 400 т/ч | Расход при 100% (для модели) |

Упреждение `rStopLead` подбирается под расход: при больших расходах (например, 4000 т/ч) итоговая
масса будет немного больше 80 т, потому что поток после остановки насоса затухает по инерции.

## Известные ограничения и идеи для развития

- Это симуляция: на реальном оборудовании нужно подключить концевики, расходомер и датчики
  вместо модели (`bSimMode = FALSE`) и проверить все защиты.
- Один режим работы (автоматический). Можно добавить ручной режим.
- Идеи: функциональные блоки `FB_Pump` и `FB_Valve`, счётчик циклов налива (CTU + R_TRIG),
  мнемосхема в CODESYS Visualization, журнал аварий, обмен по Modbus TCP или OPC UA, ПИД на давление.
